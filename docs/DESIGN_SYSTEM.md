# Lake beauty Design System

## Direction
Premium Clinical Beauty: warm, restrained, factual and editorial. Customer results lead visual hierarchy; 3D is supporting atmosphere.

## Tokens
- Background: `#F7F4EF`
- Surface: `#FFFDFA`
- Ink: `#173D34`
- Muted: `#6D7C75`
- Accent: `#DB735F`
- Border: `rgba(23, 61, 52, .15)`

Display type uses Bodoni Moda; interface and body use Manrope. Sections use `clamp()` spacing and cards use square-to-soft `0-10px` corners only.

## Motion
Use 200-500ms fades, translations, or scale. Respect `prefers-reduced-motion`; WebGL remains decorative and has a CSS fallback.

## Image Rules
Use only verified, unfiltered business images. Every result must include paired original images. Missing assets stay as explicit placeholders until provided.
